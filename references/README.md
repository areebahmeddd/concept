# Reference Library

The verified sources behind the design, each graded, with the fact kept separate from the lesson this game draws from it.

> **Version:** v0.1 · **Updated:** 10-10-2026 · **Owner:** Design lead
>
> **Related:** [Conventions](../docs/00-meta/conventions.md#5-sources-and-citations) · [Decision Log](../DECISIONS.md) · [Tech Watch](../docs/08-technology/tech-watch.md) · [Regulatory Watch](../docs/12-legal/regulatory-watch.md)

## How the library works

1. **Verify, then cite.** Every fact is checked against its source and graded **P** (primary: official documentation, the developer, a regulator, a paper), **S** (secondary: press or a reputable wiki) or **W** (weak or vendor: corroborate before relying on it).
2. **Fact, then lesson.** Each entry states the verified fact first. The lesson after it says what this game takes and what it changes. Inspiration is never copying.
3. **IDs are permanent.** An ID is never changed or reused.
4. **Fast movers are re-checked.** AI, law, platforms and engines change quickly, so [Tech Watch](../docs/08-technology/tech-watch.md) and [Regulatory Watch](../docs/12-legal/regulatory-watch.md) schedule re-checks.
5. **Nothing is invented.** A claim that rests on one weak source says so in words, and no spec relies on it as fact.

The **N series** (N1 to N31) covers works across games, anime, film and music. Each N entry is summarised in the file for its medium, and every N source is listed in one table in [Film, Literature and Music](film-literature-and-music.md#n-series-sources).
